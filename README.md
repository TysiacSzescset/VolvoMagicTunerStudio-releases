# VolvoMagicTunerStudio - release
Downloads for Volvo Magic Tuner Studio

Volvo P80, P2, P1 ECU OBD reading/writing tool.
Works with DICE or Mongoose clone.

Support for reading/clearing diagnostic trouble codes (DTCs), including detailed error descriptions.

Writing to the flash memory is free and unrestricted.
Reading from the flash memory is encrypted.
Please contact me if you wish to decrypt the read content.

**WARNING** Do not flash random files found on the internet—even ones you have modified yourself—unless you are 100% certain of what you are doing. It is very easy to “brick” ECU, and an incorrect or poorly tuned file can even lead to damage to the engine itself.
